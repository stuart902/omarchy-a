J71b local microphone acceptance

Open this saved file in Firefox with Ctrl+O. No server, account, extra recorder, upload or playback is used. This page works only from a local file: URL. It makes no network requests.

  1. Make sure the already-installed conditioned microphone service is running.
  2. Click Record. In Firefox's microphone permission prompt, explicitly choose J71b Microphone (conditioned), then allow access for this take. Do not choose Default or the raw microphone. If the exact source is absent, cancel. This page cannot list labels before permission.
  3. Say a short phrase at normal volume. Keep this tab visible; hiding it stops and discards an unfinished take. Recording ends after about 10 seconds. Cancel discards the take. Check the source, settings and ended status below.
  4. Download only if you want to keep the take. There is no automatic download. A new take or closing this page discards unsaved files.

If Firefox reused a permission or selected the wrong source, this page refuses to record it. Use Firefox's microphone permission control to clear that grant, then explicitly try again. Do not change browser security settings if local-file capture is unavailable; report that limitation instead.

Echo cancellation, automatic gain control and noise suppression are requested off. The reported settings, including “not reported”, are shown below; a request alone does not prove they were disabled.
